DIAGNÓSTICO DE RED · PUERTOS UTILIZADOS

Señalización: salida TCP 443 hacia 0.peerjs.com (conexión segura para encontrar la sala).

STUN: salida UDP 19302 hacia stun.l.google.com, para descubrir cómo llegar al otro jugador.

Partida P2P: WebRTC intenta conectar los navegadores directamente por UDP usando puertos dinámicos; no existe un único puerto UDP fijo para abrir.

Importante: no hace falta abrir puertos entrantes manualmente. Pero esta versión no incorpora TURN: si la red bloquea UDP o la conexión directa entre equipos, el juego no puede retransmitir el tráfico por TCP 443.

Educacyl / RCE: un Plan Digital de un IES de Castilla y León (curso 2023–24) describe una configuración RCE con solo TCP 80 y 443 habilitados por defecto. No confirma la regla exacta de todos los institutos, pero el bloqueo de UDP sería compatible con ese escenario.
